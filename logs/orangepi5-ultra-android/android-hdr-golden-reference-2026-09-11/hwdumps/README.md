# hwdumps

`live-probe-1/` is an unscheduled capture taken the moment HDR playback was
first observed, before the G0–G4 sequence was driven deliberately. Its
screenshot shows playing video with the OSD raised, so it is a second,
independent sample of G2.

It is kept because it was taken from a Kodi session state this run did not
otherwise reproduce (the OSD raised by the operator rather than by a key event)
and it agrees with `g2-hdr-osd/` field for field.
